# MNIST Digit Classifier

Udacity Masters in AI — Introduction to Deep Learning Project

## Results
- **Test Accuracy: 97.05%** (target ≥90%)
- Architecture: 784 → 256 → 128 → 10 (FC + ReLU + Dropout)
- Optimizer: Adam (lr=0.001), 15 epochs, batch size 64

- `mnist_digit_classifier.ipynb` — Full notebook with code, training, and evaluation
- `mnist_classifier.pth` — Saved model weights
- `training_curves.png` — Loss and accuracy curves
